# ご近所情報ボード（骨格プロトタイプ）

平時はご近所の生活情報を共有し、災害時には住民どうしで「使えるトイレ・給水・ガソリン・通れる道・物資・避難所」などの
"生の・超ローカルな情報" を交換するためのアプリ。その **骨格が成立するか** だけを確かめる最小版です。

**公開URL: https://tk3364.github.io/kokkaku-prototype/**

## このプロトタイプで確かめたいこと

「一件の情報が、一覧・地図・最新順で姿を変えても破綻せず、"同じ一件" だと体感できるか」——これだけです。
中身の正しさ（レーン設計・信頼設計・外部連携・二モード）は扱っていません。

触ったあとに「一覧・地図・最新の投稿が一つのアプリとして自然」か「無理がある」かを言葉にしてもらえると助かります。

## 触りかた

- **一覧が主役**。上のプルダウンでジャンル絞り込み・並び替え（新しい順／近い順／使える順／継続中が多い順／書き込みが多い順／ジャンル順）
- **カードを選ぶと地図のピンが強調**され、その位置へ移動します。逆に**ピンを押すと一覧の該当カードへスクロール**します（同期の確認がこのアプリの肝です）
- 地図タブではカードが**ポップアップ**で重なって出ます（右上の ✕ で閉じます）
- カード下部の **👍継続中 / ⚠️変化あり / ✕削除依頼**、および **「今どう？」欄への書き込み**で情報を更新できます
- 右下の **📍現在地 / ＋投稿**。投稿は「現在地を使う」か地図クリックで場所を指定します

## 仕様メモ（プロトタイプの割り切り）

- データは**メモリ上のみ**。リロードすると初期状態（ダミー32件）に戻ります。バックエンド・保存・認証はありません
- 位置は全件で必ず保持し、**公開＝地図にピン／非公開＝一覧のみ**（座標は消えません）
- 同じ項目への操作は**5分に1回**。削除依頼が**3件を超えると投稿が消えます**
- 同じ場所（同名 or 30m以内）かつ同じジャンルへの投稿は、新規に立てず**既存カードへの書き込みに統合**されます
- 状態は 🟢営業中・利用可 / 🟡制限あり / 🔴休止・閉鎖 の3段階。カードの枠と背景の色に反映されます

## 開発

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/ を生成（GitHub Pages 用）
```

React + react-leaflet + OpenStreetMap。バックエンドなし。
